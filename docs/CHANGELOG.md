## 1.0.0.0（正式版）

**发布日期：** 2026-07-26

物流附属模组首个正式版：把搬运、储存与进出料接到同一套物流玩法里。

### 本版要点

- **输送带**：相邻格自动连成直线（可成坡、不会转弯）；侧面接机械动力后运转，把带上的物品送到尽头；尽头横着另一条带就转交，否则弹出。站上去会被带走，潜行可站稳；空手点一下可调转整条带方向。
- **储存库**：物流存储单元贴着放置会并入同一库，库容随相连数量增加；右键翻页查看，抓取机可从侧面存取。
- **高级物流设备**：高级抓取机、抓取阀、分拣机——电脉冲驱动；可按白名单 / 黑名单过滤。
- **料斗**：落料斗按间隔从贴合容器取货；受料斗接住掉落物并塞进机器进料口。大口正对输送带时，物品可直接上下带而不落地。
- **锌消耗**：上述设备配方大量使用锌板 / 锌片，补齐工业时代 2 的锌出口。

### 安装提示

- 需要同时启用 **工业时代 2**（版本满足依赖要求）与本模组。
- 若同时使用其它附属模组，请使用与当前工业时代 2 匹配的版本。

### 已知限制（后续版本）

- 输送带不会在同带上做 90° 转弯（直角处用两条带交接）。
- 超长输送带在极大世界中的性能、以及半加载边界的散落加固，仍会按需继续打磨。
